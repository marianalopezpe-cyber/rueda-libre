## MINI RETO 15 

- Definición de estilos base para móviles.
- Organización de la portada en una columna.
- Adaptación de la galería de rutas.
- Ajuste del formulario de reservas.
- Reorganización del encabezado y del pie de página.
- Ajuste de imágenes y tablas para evitar desbordamientos.
- Uso de media queries.

**Anchos de referencia trabajados:**
- 360 px: móvil.
- 768 px: tablet.
- 1280 px: escritorio.

**Problemas identificados y soluciones:**

1. La portada tenía dos columnas desde el estilo base y comprimía el contenido en móviles. Se estableció una columna inicial y dos columnas desde 768 px.
2. La galería tenía demasiadas columnas en pantallas pequeñas. Se reorganizó progresivamente.
3. El encabezado y el pie de página reducían el espacio disponible. Se apilaron en móviles y se recuperó la distribución horizontal en pantallas más amplias.

**nota:** comprendí la importancia de diseñar primero para pantallas pequeñas y ampliar la distribución mediante media queries.

## MINI RETO 16 

- Creación de una página de pruebas: `pruebas/catalogo-bootstrap.html`.
- Uso de `container` y `row`.
- Aplicación de clases de columnas.
- Uso de gutters mediante `g-4`.
- Comparación con la cuadrícula CSS creada anteriormente.

**Clases de Bootstrap trabajadas:**
- `col-12`.
- `col-sm-6`.
- `col-lg-4`.
- `col-xl-3`.
- `row`.
- `g-4`.

**Comparación:**

Con CSS propio se utilizaba `repeat(auto-fit, minmax(250px, 1fr))`, lo que permitía controlar con mayor precisión el ancho mínimo de las tarjetas.

Con Bootstrap se utilizaron clases predefinidas para conseguir una distribución responsive con menos reglas CSS.

**nota:** comprendí que Bootstrap facilita la construcción de layouts mediante clases reutilizables, aunque ofrece menos control específico que algunas reglas CSS personalizadas.

**Decisión del proyecto:** se mantuvo el criterio de no utilizar JavaScript propio. La comparación se realizó mediante Bootstrap CSS.

## MINI RETO 18 

**Portada:**
- Uso de `container`.
- Uso de `row`.
- Distribución mediante `col-12` y `col-lg-6`.
- Alineación con `align-items-center`.
- Separación mediante `g-4` y `g-lg-5`.

**Flota:**
- Migración de la cuadrícula a clases de Bootstrap.
- Conservación de las siete bicicletas.
- Uso de `row-cols-1`, `row-cols-md-2`, `row-cols-lg-3` y `row-cols-xl-4`.
- Conservación del distintivo «Nuevo».

**Rutas:**
- Uso de `row-cols-1`, `row-cols-md-2` y `row-cols-lg-3`.
- Adaptación de las tarjetas a la estructura de Bootstrap.

**Beneficios:**
- Ajuste de la distribución mediante `row-cols`.
- Reorganización de las tarjetas según el tamaño de pantalla.

**Conflictos de cascada identificados:**

1. Las reglas anteriores de Grid podían competir con las clases `row` y `col` de Bootstrap. Se retiraron las reglas de distribución que ya resolvía el framework.
2. Los estilos globales de títulos podían competir con las utilidades de Bootstrap. Se mantuvo la identidad tipográfica en la hoja propia.
3. Los colores predeterminados de enlaces y botones podían diferir de la marca. Se conservaron los colores de Rueda Libre en `styles.css`.

**nota:** comprendí cómo integrar Bootstrap con CSS propio y cómo controlar la cascada para evitar conflictos entre estilos.

**Decisión:** Bootstrap CSS se carga antes de `CSS/styles.css`. No se utiliza `!important`.

Durante los ajustes de CSS el botón flotante perdió su apariencia y llegó a mostrarse como un pequeño icono en la esquina inferior izquierda.

Se revisó la clase `.whatsapp-flotante` y se ajustaron:
- Posicionamiento fijo.
- Ubicación en la esquina inferior derecha.
- Fondo verde de marca.
- Icono y texto.
- Bordes redondeados.
- Sombra.
- Estado hover.
- Estado de foco visible.
- Tamaño para dispositivos móviles.

## Ajuste del carrusel de promociones

Durante la revisión visual se observó que los textos de las promociones no tenían suficiente contraste con las fotografías.

Inicialmente se intentaron aplicar estilos con selectores que no correspondían a la estructura real del HTML.

Al revisar el código se identificó que el carrusel utilizaba los componentes nativos de Bootstrap:

- `.carousel`.
- `.carousel-inner`.
- `.carousel-item`.
- `.carousel-caption`.
- `.imagen-promocion`.

Se corrigió el enfoque de los estilos para trabajar con las clases reales del carrusel.

**Ajustes preparados:**
- Altura de las diapositivas.
- Imágenes con `object-fit: cover`.
- Fondo oscuro mediante un pseudo-elemento `::after`.
- Texto blanco sobre el fondo.
- Posicionamiento del contenido.
- Ajustes responsive para móviles.

**nota:** comprendí que los selectores CSS deben corresponder exactamente con las clases y la estructura del HTML. También aprendí que, antes de agregar nuevas reglas, es importante identificar si existe un conflicto entre los estilos anteriores y los nuevos.

# CIERRE DEL PROYECTO

Rueda Libre pasó de ser una estructura inicial de HTML a convertirse en un sitio web de varias páginas, con una identidad visual definida, una organización responsive y componentes construidos con CSS y Bootstrap.

A lo largo de los Mini Retos fui incorporando nuevos conocimientos y aplicándolos directamente al proyecto. También tuve que identificar y corregir problemas relacionados con la distribución de elementos, la adaptación a diferentes pantallas, la cascada de CSS y la legibilidad de los contenidos.

Uno de los aprendizajes más importantes fue comprender que no basta con conseguir que una página se vea bien: también es necesario que el código esté organizado, que los elementos tengan una función clara y que la experiencia sea consistente en diferentes dispositivos.

La versión 2.0 representa la consolidación de los conocimientos trabajados durante el proceso y la evolución visual y técnica de Rueda Libre.

**Estado de cierre:** versión 2.0 preparada para revisión y entrega. La publicación definitiva y las pruebas finales deben confirmarse desde el repositorio y el navegador.
